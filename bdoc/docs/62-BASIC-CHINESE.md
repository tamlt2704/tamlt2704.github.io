## PART 1: Pronunciation & Tones

## 62.1 The 4 tones (MOST important thing to learn)

```
MANDARIN HAS 4 TONES + 1 NEUTRAL:
Same syllable, different tone = COMPLETELY different meaning

  mā (1st: flat high)    = mother 妈
  má (2nd: rising)       = hemp 麻
  mǎ (3rd: dip/valley)  = horse 马
  mà (4th: falling)      = scold 骂

Tone 1: ───── (high, flat — like singing a note)
Tone 2: ╱     (rising — like asking "huh?")
Tone 3: ╲╱    (dip down then up — like saying "well..." hesitantly)
Tone 4: ╲     (sharp falling — like a command "Stop!")
Neutral: · (short, light — unstressed)

PRACTICE:
  Say "ma" in all 4 tones: mā má mǎ mà
  Say "shi": shī shí shǐ shì (teacher, ten, history, yes)
  
IF YOU GET TONES WRONG:
  You might say "I want to kiss you" instead of "I want to ask you"
  (wěn 吻 = kiss vs wèn 问 = ask)
  Tones are NOT optional! Practise from day one.
```

## 62.2 Pinyin pronunciation guide

```
INITIALS (consonants) — most sound like English:
  b, p, m, f        = as English
  d, t, n, l        = as English
  g, k, h           = as English
  j                  = like "jeep" (but softer)
  q                  = like "cheese" (with more air)
  x                  = like "she" (tongue forward)
  zh                 = like "judge" (tongue curled back)
  ch                 = like "church" (tongue curled back)
  sh                 = like "shirt" (tongue curled back)
  r                  = like "pleasure" (tongue curled back)
  z                  = like "seeds" (no aspiration)
  c                  = like "bits" (with air)
  s                  = like "see"

TRICKY ONES:
  j, q, x → tongue FORWARD (tip behind lower teeth)
  zh, ch, sh, r → tongue CURLED BACK (retroflex)
  
FINALS (vowels):
  a = "ah" (father)
  o = "aw" (more)
  e = "uh" (duh) — NOT "ee"
  i = "ee" (see) — EXCEPT after zh/ch/sh/r/z/c/s where it's a buzz
  u = "oo" (food)
  ü = "ee" with rounded lips (French "tu") — only after j/q/x/l/n

COMBINATIONS:
  ai = "eye"          ei = "ay" (day)
  ao = "ow" (cow)     ou = "oh" (go)
  an = "ahn"          en = "un" (fun)
  ang = "ahng"        eng = "ung" (lung)
  ong = "oong"
  ian = "yen"         iang = "yahng"
  iu = "yo"           ui = "way"
```

## PART 3: Numbers, Time & Money

## 62.8 Numbers (0-99)

```
0  零 líng          10 十 shí
1  一 yī            11 十一 shí yī
2  二 èr            12 十二 shí èr
3  三 sān           20 二十 èr shí
4  四 sì            21 二十一 èr shí yī
5  五 wǔ            30 三十 sān shí
6  六 liù           50 五十 wǔ shí
7  七 qī            99 九十九 jiǔ shí jiǔ
8  八 bā
9  九 jiǔ

100   一百  yì bǎi
1000  一千  yì qiān
10000 一万  yí wàn  (Chinese counts in 10-thousands, not thousands!)

PHONE NUMBER: read digit by digit
  9123 4567 = jiǔ yāo èr sān, sì wǔ liù qī
  (1 becomes "yāo" in phone numbers to avoid confusion with 7 "qī")
```

## 62.9 Time

```
ASKING TIME:
  几点了？(jǐ diǎn le?) = What time is it?

TELLING TIME:
  三点      (sān diǎn)        = 3:00
  三点半    (sān diǎn bàn)    = 3:30 (half)
  三点十五  (sān diǎn shí wǔ) = 3:15
  下午三点  (xià wǔ sān diǎn) = 3:00 PM

DAYS:
  今天 (jīn tiān) = today
  明天 (míng tiān) = tomorrow
  昨天 (zuó tiān) = yesterday
  星期一 (xīng qī yī) = Monday (week-one)
  星期二 through 星期六 = Tues-Sat
  星期天/日 (xīng qī tiān/rì) = Sunday
```

## 62.10 Money

```
CHINESE CURRENCY:
  Official: 元 (yuán)   = dollar/yuan
  Colloquial: 块 (kuài) = buck (informal)
  Cents: 毛 (máo) = 10 cents (jiao)

EXAMPLES:
  ¥25.50 = 二十五块五 (èr shí wǔ kuài wǔ)
  ¥8 = 八块 (bā kuài)
  ¥100 = 一百块 (yì bǎi kuài)

SINGAPORE DOLLARS (in Singapore context):
  Just use numbers + 块: 三块五 = $3.50
```

## PART 4: Grammar (Surprisingly Simple!)

## 62.11 Why Chinese grammar is easier than English

```
NO CONJUGATION:
  English: I go, he goes, they went, she will go, we have gone
  Chinese: 我去, 他去, 他们去, 她会去, 我们去了 (verb never changes!)
  去 (qù = go) is ALWAYS 去. Always.

NO TENSES (context + time words instead):
  I go tomorrow     = 我明天去 (wǒ míng tiān qù)
  I went yesterday  = 我昨天去了 (wǒ zuó tiān qù le)
  I am going now    = 我现在去 (wǒ xiàn zài qù)
  The verb 去 never changes! Just add time word + 了 for completion.

NO PLURALS:
  one cat  = 一只猫 (yì zhī māo)
  five cats = 五只猫 (wǔ zhī māo)
  猫 (cat) is always 猫. No "cats."

NO ARTICLES (no "a", "an", "the"):
  "I see a cat" = 我看到猫 (wǒ kàn dào māo) — no article needed!
```

## 62.12 Basic sentence structure

```
CHINESE WORD ORDER: Subject + Time + Place + Verb + Object

ENGLISH:  I     ate   noodles   yesterday   at the restaurant.
CHINESE:  我    昨天   在餐厅      吃了      面。
          I  yesterday at restaurant ate    noodles.
          (wǒ zuó tiān zài cān tīng chī le miàn)

QUESTIONS (2 ways):

1. Add 吗 (ma) to the end (yes/no questions):
   你是学生。(You are a student.) → 你是学生吗？(Are you a student?)
   
2. Use question words IN PLACE of the answer:
   你去哪里？(nǐ qù nǎ lǐ?) = You go WHERE? → Where are you going?
   这是什么？(zhè shì shén me?) = This is WHAT? → What is this?
   你要几个？(nǐ yào jǐ ge?) = You want HOW MANY? → How many do you want?

NEGATION:
   不 (bù) = not (for present/future, habits):  我不吃辣 (I don't eat spicy)
   没 (méi) = didn't / haven't (for past):      我没去 (I didn't go)
```

## 62.13 Essential grammar patterns

```
1. 是 (shì) = to be (for identity — NOT for adjectives!)
   我是老师 (wǒ shì lǎo shī) = I am a teacher
   这是我的 (zhè shì wǒ de) = This is mine

2. 很 (hěn) + adjective (for descriptions — NOT 是!)
   ❌ 我是累 (I am tired — WRONG!)
   ✅ 我很累 (wǒ hěn lèi) = I'm tired
   ✅ 天气很热 (tiān qì hěn rè) = The weather is hot

3. 的 (de) = possessive / modifier
   我的手机 (wǒ de shǒu jī) = my phone
   红色的车 (hóng sè de chē) = red car

4. 了 (le) = completed action / change of state
   我吃了 (wǒ chī le) = I ate (completed)
   下雨了 (xià yǔ le) = It started raining (change!)

5. 会 (huì) = can (learned ability) / will (future)
   我会说中文 (wǒ huì shuō zhōng wén) = I can speak Chinese
   明天会下雨 (míng tiān huì xià yǔ) = It will rain tomorrow

6. 可以 (kě yǐ) = can (permission) / may
   我可以坐这里吗？(wǒ kě yǐ zuò zhè lǐ ma?) = Can I sit here?

7. 想 (xiǎng) = want to / think / miss
   我想吃面 (wǒ xiǎng chī miàn) = I want to eat noodles
   我想你 (wǒ xiǎng nǐ) = I miss you
```

## PART 5: Common Conversations

## 62.14 In a taxi

```
You:    师傅，去 [place]        Shī fu, qù [place]
        Driver, go to [place]

You:    到了吗？              Dào le ma?
        Are we there?

Driver: 快到了                Kuài dào le
        Almost there

You:    这里停                Zhè lǐ tíng
        Stop here

You:    多少钱？              Duō shao qián?
        How much?

Driver: 十五块                Shí wǔ kuài
        15 dollars

You:    谢谢师傅              Xiè xie shī fu
        Thanks driver
```

## 62.15 At a restaurant

```
Staff:  几位？                  Jǐ wèi?
        How many people?

You:    两位                    Liǎng wèi
        Two people

You:    有英文菜单吗？          Yǒu yīng wén cài dān ma?
        Do you have English menu?

You:    我要这个和这个          Wǒ yào zhè ge hé zhè ge
        I want this one and this one (point at menu)

You:    不要辣的                Bú yào là de
        No spicy

Staff:  要喝什么？              Yào hē shén me?
        What do you want to drink?

You:    一杯水                  Yì bēi shuǐ
        One glass of water

You:    买单                    Mǎi dān
        Bill please

You:    可以刷卡吗？            Kě yǐ shuā kǎ ma?
        Can I pay by card?
```

## 62.16 Shopping

```
You:    这个多少钱？            Zhè ge duō shao qián?
        How much is this?

Seller: 五十块                  Wǔ shí kuài
        50 dollars

You:    太贵了！三十块行吗？    Tài guì le! Sān shí kuài xíng ma?
        Too expensive! 30 OK?

Seller: 不行，最少四十          Bù xíng, zuì shǎo sì shí
        No, minimum 40

You:    好吧，四十              Hǎo ba, sì shí
        OK, 40

You:    有别的颜色吗？          Yǒu bié de yán sè ma?
        Do you have other colours?

You:    可以试吗？              Kě yǐ shì ma?
        Can I try it?

You:    有大一点的吗？          Yǒu dà yì diǎn de ma?
        Do you have a bigger one?
```

## PART 6: Learning Tips

## 62.17 How to learn faster

```
1. TONES FIRST (week 1-2):
   Get tones into your muscle memory BEFORE learning vocabulary.
   Wrong tones = permanent bad habits that are very hard to fix later.
   Use: Tone training apps (Pleco tone drills, ChinesePod tone pairs)

2. LISTEN MORE THAN YOU READ:
   Chinese is a SPOKEN language first. Read pinyin, don't rely on characters initially.
   Listen to: podcasts (ChinesePod, MandarinCorner), dramas with subtitles

3. LEARN PHRASES, NOT WORDS:
   Don't memorize 吃 (eat) alone. Learn 我想吃面 (I want to eat noodles).
   Phrases give you grammar patterns automatically.

4. SPEAK FROM DAY 1:
   Don't wait until you're "ready." Use what you know:
   Week 1: 你好, 谢谢, 再见 (hello, thanks, bye)
   Week 2: order food in Chinese (even just pointing + 这个)
   Week 3: taxi conversations
   
5. CHARACTERS CAN WAIT:
   For communication, pinyin is enough to start.
   Learn characters later when you have vocabulary foundation.
   (Exception: if living in China, learn 100 high-frequency characters for signs/menus)

6. USE DAILY (even 10 minutes):
   • Change phone language to Chinese
   • Label household items (冰箱 = fridge, 门 = door)
   • Speak to yourself while cooking, showering (describe what you're doing)
   • HelloChinese app (best for beginners — free, gamified)
```

## Summary

✅ 4 tones: flat (ā), rising (á), dip (ǎ), falling (à) — get these right first!
✅ Pinyin pronunciation: initials + finals + tone = complete syllable
✅ Survival phrases: greetings, directions, food, shopping, emergencies
✅ Numbers 0-99, time (点/half), money (块/毛)
✅ Grammar is SIMPLE: no conjugation, no tenses (use time words), no plurals, no articles
✅ Sentence order: Subject + Time + Place + Verb + Object
✅ Questions: add 吗 (yes/no) or use question word in place of answer
✅ Negation: 不 (present/habit) vs 没 (past)
✅ Key patterns: 是 (identity), 很+adj (description), 了 (completed), 会 (ability), 想 (want)
✅ Real conversations: taxi, restaurant, shopping (with haggling!)

## Key takeaways

**Tones are non-negotiable.** Chinese with wrong tones is like English with random vowels — "I wont te git soom faid" — technically has the right consonants but nobody understands you. Nail tones in week 1.

**Grammar is your friend.** After English (irregular verbs, 12 tenses, articles, plurals), Chinese grammar is refreshingly logical. One verb form. Time words for tense. Measure words for counting. That's mostly it.

**Don't wait to be "ready" — USE IT.** Order coffee in Chinese. Count in Chinese. Say thank you in Chinese. Every tiny real-world use builds confidence and muscle memory faster than any textbook.

**10 minutes daily beats 2 hours on Saturday.** Language is a muscle. Daily input (even just a podcast while commuting) compounds dramatically over weeks and months.
