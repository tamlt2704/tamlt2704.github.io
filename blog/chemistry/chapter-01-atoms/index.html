Atomic Number & Mass Number

Mass number (A) = protons + neutrons ᴬ X Element symbol Z Atomic number (Z) = protons = electrons (neutral atom)

Example: Carbon-12: ¹²C₆ → 6 protons, 6 neutrons, 6 electrons

Isotopes

Same element, different neutrons:

¹²C (6p, 6n) ¹³C (6p, 7n) ¹⁴C (6p, 8n) All are carbon — same chemical properties

Electron Configuration

Electrons fill orbitals in order of energy:

1s² 2s² 2p⁶ 3s² 3p⁶ 4s² 3d¹⁰ 4p⁶ ... Example: Oxygen (8 electrons) 1s² 2s² 2p⁴ Shell diagram: (2) (6) ← wrong, oxygen only has 8 (2) (2)(4) K L ← shells

Practice Problems

P1. An atom has 17 protons, 18 neutrons. Identify it and give mass number.

Solution: Z=17 → Chlorine (Cl), A = 17+18 = 35 → ³⁵Cl

P2. Write electron configuration for Calcium (Z=20).

Solution: 1s² 2s² 2p⁶ 3s² 3p⁶ 4s² (or [Ar] 4s²)

P3. How many valence electrons does Sulfur (Z=16) have?

Solution: Config: [Ne] 3s² 3p⁴ → 6 valence electrons (Group 16)

P4. Two isotopes: ⁶³Cu and ⁶⁵Cu. Both have how many protons?

Solution: Cu = copper, Z=29. Both have 29 protons. (63-29=34 neutrons vs 65-29=36 neutrons)
