Git Mastery: From Beginner to Advanced

This guide takes you from your first git init to understanding Git's internal object model. Each chapter builds on the previous, with practical exercises to reinforce concepts.

Chapters

  1. Basics — init, clone, add, commit, status, log, diff. The three areas of Git.
  2. Branching — branch, checkout, switch, merge, HEAD explained.
  3. Remotes — remote add, fetch, pull, push, upstream tracking, fork workflow.
  4. Merge vs Rebase — When to use each, interactive rebase, conflict resolution, rerere.
  5. Undoing Things — amend, reset, revert, restore, clean, reflog.
  6. Team Workflows — Git Flow, GitHub Flow, Trunk-based, pull requests, CODEOWNERS.
  7. Advanced — cherry-pick, stash, bisect, worktrees, submodules, hooks.
  8. Internals — objects, SHA-1, packfiles, how branches and merges work internally.

Who This Is For

  • Developers who use Git daily but want deeper understanding
  • Teams looking to standardize their Git workflow
  • Anyone curious about how Git actually works under the hood

Prerequisites

  • A terminal (bash, zsh, PowerShell, etc.)
  • Git installed (git --version to verify)
  • A text editor

How to Use This Guide

Work through chapters sequentially or jump to topics you need. Each chapter ends with hands-on exercises. Type the commands yourself — muscle memory matters.
