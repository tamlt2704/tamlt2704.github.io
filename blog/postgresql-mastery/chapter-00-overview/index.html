PostgreSQL Mastery

A comprehensive guide to PostgreSQL — from basics to production clusters.

Chapters

  1. Setup & Installation — Docker, psql, pgAdmin, configuration
  2. SQL Basics — Tables, data types, CRUD operations
  3. Intermediate Queries — JOINs, CTEs, window functions
  4. Indexes — B-tree, GIN, GiST, EXPLAIN ANALYZE
  5. Advanced Features — Views, procedures, partitioning, triggers
  6. JSONB — Storing, querying, indexing JSON data
  7. Performance Tuning — Configuration, VACUUM, query optimization
  8. Security — Roles, RLS, SSL, audit logging
  9. Backup & Recovery — pg_dump, WAL archiving, PITR
  10. Replication & Clustering — Streaming replication, Patroni, failover

Who This Is For

  • Developers who want to go beyond basic SELECT statements
  • Backend engineers building data-intensive applications
  • DevOps/SREs managing PostgreSQL in production

Prerequisites

  • Basic command-line familiarity
  • Docker installed (for the setup chapter)
  • A text editor and terminal

Convention

All SQL examples are runnable directly in psql. Output examples are shown where helpful. Each chapter ends with practical exercises.
