Chapter 3: Copy Mode

prev: Windows & Panes | next: Configuration

Entering Copy Mode

KeyAction
C-b [Enter copy mode
C-b ]Paste from tmux buffer
qExit copy mode

In copy mode you can scroll through the scrollback buffer, search text, and copy selections.

Navigation (vi mode)

Enable vi mode in your config:

setw -g mode-keys vi
KeyAction
h j k lMove left/down/up/right
wNext word
bPrevious word
C-uPage up
C-dPage down
gTop of buffer
GBottom of buffer
0Start of line

Navigation (emacs mode, default)

Searching

KeyAction
/Search forward (vi mode)
?Search backward (vi mode)
nNext match
NPrevious match
C-sSearch forward (emacs mode)
C-rSearch backward (emacs mode)

Selecting and Copying (vi mode)

KeyAction
SpaceStart selection
EnterCopy selection and exit
vStart selection (with custom bindings)
yYank/copy (with custom bindings)

Enhanced vi-copy Bindings

bind-key -T copy-mode-vi v send-keys -X begin-selection
bind-key -T copy-mode-vi y send-keys -X copy-selection-and-cancel
bind-key -T copy-mode-vi r send-keys -X rectangle-toggle

Scrollback Buffer

# Set scrollback buffer size (default 2000 lines)
set -g history-limit 50000

Copy to System Clipboard

Linux (xclip)

bind-key -T copy-mode-vi y send-keys -X copy-pipe-and-cancel "xclip -selection clipboard"

macOS (pbcopy)

bind-key -T copy-mode-vi y send-keys -X copy-pipe-and-cancel "pbcopy"

WSL

bind-key -T copy-mode-vi y send-keys -X copy-pipe-and-cancel "clip.exe"

Mouse Mode

set -g mouse on

With mouse mode on:

  • Scroll wheel enters copy mode and scrolls
  • Click and drag to select text
  • Right-click to paste (depending on terminal)
