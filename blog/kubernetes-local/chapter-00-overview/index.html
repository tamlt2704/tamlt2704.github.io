Kubernetes Locally — Learn Without Cloud Bills

This course teaches Kubernetes using local clusters only. You will use minikube, kind, or Docker Desktop Kubernetes. No cloud account, no credit card, no surprise bills.

By the end you will be comfortable deploying, scaling, debugging, and observing applications on Kubernetes.

Chapters

  1. Setup - Your First Local Cluster
  2. Pods - The Smallest Deployable Unit
  3. Deployments - Scaling and Updates
  4. Services and Networking
  5. Configuration - ConfigMaps and Secrets
  6. Storage - Persistence in Kubernetes
  7. Helm - Package Manager for Kubernetes
  8. Observability - Monitoring and Autoscaling
  9. Projects - Full-Stack Deployments

Prerequisites

  • A machine with at least 4 GB RAM free for the cluster
  • Docker installed (required for all local K8s options)
  • Basic terminal/command-line familiarity
  • Familiarity with containers (docker run, Dockerfile basics)

What You Will Learn

  • Create and manage local Kubernetes clusters
  • Deploy applications with Pods, Deployments, and Services
  • Configure apps with ConfigMaps and Secrets
  • Persist data with Volumes and StatefulSets
  • Package apps with Helm charts
  • Monitor with Prometheus and Grafana
  • Build real projects: full-stack apps, blue-green and canary deployments
