Manim - Mathematical Animation Engine

Create beautiful math animations with Python. Manim is the library 3Blue1Brown uses to produce stunning mathematical visualizations.

Chapters

  • Chapter 1: Setup - Installation, first scene, running animations
  • Chapter 2: Shapes & Mobjects - Circles, squares, positioning, groups
  • Chapter 3: Animations - FadeIn, Transform, timing, rate functions
  • Chapter 4: Text & LaTeX - Text rendering, math equations, formatting
  • Chapter 5: Graphs & Plots - Axes, functions, parametric curves, bar charts
  • Chapter 6: 3D Scenes - 3D objects, surfaces, camera rotation
  • Chapter 7: Advanced - Custom animations, updaters, SVG import
  • Chapter 8: Projects - Sorting, Fourier, linear algebra, calculus

What You Can Build

  • Explanatory math videos like 3Blue1Brown
  • Algorithm visualizations
  • Physics simulations
  • Data visualizations with animated transitions
  • Educational content with step-by-step equation reveals

Quick Start

from manim import *

class HelloManim(Scene):
    def construct(self):
        text = Text("Hello, Manim!")
        self.play(Write(text))
        self.wait()

Render it:

manim -pql scene.py HelloManim
