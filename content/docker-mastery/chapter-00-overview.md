# Docker Mastery: From Zero to Production

A comprehensive guide to Docker — from your first container to production-ready deployments.

## Chapters

1. [Docker Basics](./chapter-01-basics.md) — What is Docker, containers vs VMs, installation, first commands
2. [Docker Images](./chapter-02-images.md) — Dockerfile instructions, multi-stage builds, layer caching
3. [Volumes & Data](./chapter-03-volumes.md) — Data persistence, bind mounts, backup strategies
4. [Networking](./chapter-04-networking.md) — Bridge, host, port mapping, container communication
5. [Docker Compose](./chapter-05-compose.md) — Multi-container apps, services, profiles
6. [Registries](./chapter-06-registry.md) — Docker Hub, private registries, tagging strategy
7. [Production](./chapter-07-production.md) — Health checks, security, resource limits, slim images
8. [Real Projects](./chapter-08-projects.md) — Spring Boot, Next.js, full-stack compose, CI/CD

## Prerequisites

- A machine with at least 4GB RAM
- Windows 10/11, macOS, or Linux
- Basic terminal/command-line knowledge

## How to Use This Guide

Each chapter builds on the previous one. Follow them in order for the best learning experience. Every chapter includes:

- Conceptual explanations
- CLI commands you can run immediately
- Dockerfile examples
- Practical exercises

Start with [Chapter 1: Docker Basics](./chapter-01-basics.md) to begin your journey.
