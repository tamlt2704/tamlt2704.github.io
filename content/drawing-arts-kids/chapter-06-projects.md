## Project 1: Birthday Card 🎂

**Materials:** Folded paper, colors

**Steps:**

1. Fold paper in half
2. Draw on the FRONT:

```
Front of card:
┌─────────────────┐
│                 │
│   ╭─╮ ╭─╮ ╭─╮ │  ← balloons (ovals)
│   │╱ │╱ │╱    │
│    ╲╱  ╲╱     │  ← strings
│                 │
│  HAPPY          │
│  BIRTHDAY!      │
│                 │
│     ╭───╮       │
│    ╱ 🕯🕯╲      │  ← cake
│   │░░░░░│      │
│   │═════│      │
│   └─────┘      │
└─────────────────┘
```

3. Inside: Write your message and draw something the person likes!

## Project 2: 4-Panel Comic Strip 📰

**Tell a short funny story in 4 boxes!**

```
┌─────────┬─────────┐
│ Panel 1 │ Panel 2 │
│         │         │
│  (Set   │ (Some-  │
│  the    │  thing  │
│  scene) │ happens)│
├─────────┼─────────┤
│ Panel 3 │ Panel 4 │
│         │         │
│  (Oh    │ (Funny  │
│   no!)  │ ending!)│
│         │         │
└─────────┴─────────┘
```

**Example story: "The Hungry Cat"**

```
Panel 1: Cat sees fish bowl    Panel 2: Cat reaches in
   🐱 👀 🐟                      🐱🤚...🐟

Panel 3: Fish splashes cat     Panel 4: Wet angry cat
   💦🐱💦                        😾 (fish is smiling 🐟😏)
```

**Tips for comics:**

- Keep drawings simple
- Use speech bubbles for talking
- Use "!" and "?" for emotions
- Sound effects: "BOOM!", "SPLASH!", "ZAP!"

## Project 4: Design Your Own Character 🦸

Create a superhero, monster, or fantasy creature!

**Character Design Sheet:**

```
┌────────────────────────────┐
│  Name: ________________    │
│  Power: _______________    │
│                            │
│    Front:      Side:       │
│    ╭──╮       ╭──╮        │
│    │  │       │  │        │
│    ├──┤       ├──┤        │
│    │  │       │  │        │
│    ┤  ├       │  │        │
│    └┬┬┘       └┬─┘        │
│     ││         │          │
│                            │
│  Expressions:              │
│  😊  😠  😲  😎           │
│                            │
│  Special items:            │
│  (draw their weapon/tool)  │
└────────────────────────────┘
```

Think about:

- What colors are they?
- Do they have a cape, wings, or tail?
- What's their symbol/logo?
