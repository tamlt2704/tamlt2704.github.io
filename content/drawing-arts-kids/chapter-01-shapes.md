# Chapter 1: Basic Shapes & Lines

## The Building Blocks of Drawing

Every drawing is made of simple shapes! Let's learn them:

```
Circle      Square      Triangle    Oval        Rectangle
  ○           □           △          ⬭           ▭
```

## Types of Lines

```
Straight:    ─────────────
Curved:      ∼∼∼∼∼∼∼∼∼∼∼
Zigzag:      /\/\/\/\/\/\
Wavy:        ∿∿∿∿∿∿∿∿∿∿∿
Dotted:      · · · · · · ·
Spiral:      @
```

## How to Hold Your Pencil

Hold it like you're writing, but a little further back from the tip. Don't squeeze too hard! Your hand should feel relaxed.

**Light lines** = press gently (for sketching)
**Dark lines** = press harder (for final drawing)

## Exercise 2: Shape Pictures 🏠

Combine shapes to make things!

**House:**

```
    △         ← triangle roof
   /  \
  /    \
 ┌──────┐    ← square body
 │  []  │    ← small square window
 │      │
 │  ┌┐  │    ← rectangle door
 └──┘└──┘
```

**Tree:**

```
    ○        ← circle (leaves)
   ○○○
    ○
    │        ← straight line (trunk)
    │
```

**Sun:**

```
  \ | /
 ── ○ ──    ← circle + lines (rays)
  / | \
```
