# Chapter 4: Colors & Shading 🌈

## The Color Wheel

```
         Red
        /    \
  Orange      Purple
      |        |
  Yellow      Blue
        \    /
         Green
```

## Primary Colors (You can't mix these!)

🔴 Red 🔵 Blue 🟡 Yellow

## Secondary Colors (Mix two primaries!)

- Red + Yellow = 🟠 Orange
- Blue + Yellow = 🟢 Green
- Red + Blue = 🟣 Purple

## Warm vs Cool Colors

```
WARM (like fire):     COOL (like water):
🔴 Red                🔵 Blue
🟠 Orange             🟢 Green
🟡 Yellow             🟣 Purple

Warm = feels close    Cool = feels far away
```

## Exercise 2: Shading Makes Things Look 3D! 🔮

The secret to making flat shapes look real: **light and shadow**.

```
Flat circle:     3D sphere:

    ○              ◐
                 (light side is white,
                  dark side is shaded)
```

**How to shade:**

1. Decide where the light comes from (pick a corner)
2. The side FACING the light stays light
3. The side AWAY from light gets darker
4. Add a shadow underneath

```
Light from top-left:

    ☀️ (light source)
     \
      ╭───╮
     │░   │     ← light side (less coloring)
     │ ░░ │
     │  ███│    ← dark side (heavy coloring)
      ╰───╯
       ▓▓▓      ← shadow on ground
```

## Shading Tips 🌟

- **Always shade in ONE direction** (don't scribble randomly)
- **Build up slowly** — add more layers for darker areas
- **Leave white spots** for shiny highlights
- **Blend** by rubbing gently with your finger or a tissue
