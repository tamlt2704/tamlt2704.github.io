# Org Mode: The Ultimate Productivity System Inside Emacs

Org Mode is a powerful document authoring, task management, and literate programming system built into GNU Emacs. It turns plain text into a complete organizational framework — from simple notes to complex project management, from quick calculations to reproducible research papers.

## Why Org Mode?

- **Plain text** — future-proof, version-controllable, grep-able
- **One tool** — notes, tasks, calendar, spreadsheets, code, publishing
- **Keyboard-driven** — fast, no context switching
- **Infinitely extensible** — it's Emacs, after all

## Getting Started

Org Mode ships with Emacs 22+. Any file ending in `.org` automatically activates org-mode.

```org
* My First Org File
** Tasks
*** TODO Learn Org Mode basics
*** TODO Set up capture templates
** Notes
   Org Mode is amazing!
```

## Prerequisites

- GNU Emacs 27+ (recommended)
- Basic Emacs navigation (C-f, C-b, C-n, C-p, C-x C-s, C-x C-f)
- Willingness to invest time upfront for massive long-term productivity gains
