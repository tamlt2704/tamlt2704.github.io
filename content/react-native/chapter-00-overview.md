# React Native: From Zero to App Store

[next: Setup](./chapter-01-setup.md)

This guide takes you from zero React Native knowledge to publishing apps on both the App Store and Google Play. We use TypeScript throughout and build with Expo SDK 51+.

## Chapters

1. [Setup & Environment](./chapter-01-setup.md) — Expo workflow, project creation, running on devices
2. [Core Components](./chapter-02-components.md) — View, Text, Image, FlatList, StyleSheet, flexbox
3. [Navigation](./chapter-03-navigation.md) — Stack, Tab, Drawer navigators with React Navigation
4. [State Management](./chapter-04-state.md) — useState, Zustand, AsyncStorage, TanStack Query
5. [Working with APIs](./chapter-05-apis.md) — fetch, axios, infinite scroll, auth tokens
6. [Forms & Input](./chapter-06-forms.md) — react-hook-form, zod, keyboard handling, pickers
7. [Native Features](./chapter-07-native-features.md) — Notifications, location, camera, biometrics
8. [Advanced Styling](./chapter-08-styling.md) — Responsive design, dark mode, animations, NativeWind
9. [Testing](./chapter-09-testing.md) — Jest, React Native Testing Library, Detox E2E
10. [Deployment](./chapter-10-deployment.md) — EAS Build, app signing, OTA updates, store submission

## Prerequisites

- Node.js 18+
- Basic React and TypeScript knowledge
- A phone (iOS or Android) for testing with Expo Go

## What You Will Build

By the end of this guide you will have built several mini-projects including a todo app, a weather app with live API data, and a full app ready for store submission.
