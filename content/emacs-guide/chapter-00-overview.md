# Emacs Guide: From Zero to Productive

[next: Getting Started](chapter-01-basics.md)

## Why This Guide

This guide takes you from never having opened Emacs to being productive in it. Each chapter builds on the previous one, but you can jump to any topic that interests you.

## Why Emacs in 2024+

- **Longevity**: Emacs has been around since 1976 and will outlive any trendy editor. Your investment pays off for decades.
- **Extensibility**: Everything is customizable through Emacs Lisp. If you can imagine a workflow, you can build it.
- **Org Mode**: The most powerful plain-text organizational system ever created — notes, tasks, spreadsheets, literate programming, and publishing in one tool.
- **Unified environment**: Email, git, file management, terminal, RSS, writing, and coding all in one consistent interface.
- **Modern ecosystem**: LSP support, tree-sitter syntax highlighting, and thousands of actively maintained packages make Emacs competitive with any modern editor.
- **Keyboard-driven**: Minimal context switching. Your hands stay on the keyboard.
