## What is Three.js?

Three.js is a JavaScript library that makes WebGL easy. It lets you create 3D scenes, animations, and interactive experiences in the browser.

## Prerequisites

- JavaScript/TypeScript basics
- Basic understanding of 3D coordinates (x, y, z)
- A browser with WebGL support (all modern browsers)

## Setup

```bash
npm install three @types/three
```
