## The Staff

Music is written on 5 lines called a **staff**:

```
Treble Clef (Right Hand):
─────── F ─── (5th line)
─────── D ─── (4th line)
─────── B ─── (3rd line)
─────── G ─── (2nd line)
─────── E ─── (1st line)

Spaces (bottom to top): F - A - C - E
```

**Memory tricks:**

- Lines: **E**very **G**ood **B**oy **D**oes **F**ine
- Spaces: **F**-**A**-**C**-**E** (spells "face")

## Bass Clef (Left Hand)

```
─────── A ─── (5th line)
─────── F ─── (4th line)
─────── D ─── (3rd line)
─────── B ─── (2nd line)
─────── G ─── (1st line)

Spaces: A - C - E - G
```

**Memory tricks:**

- Lines: **G**ood **B**oys **D**o **F**ine **A**lways
- Spaces: **A**ll **C**ows **E**at **G**rass

## Middle C

Middle C sits on a small line (ledger line) between the two staves:

```
Treble: ───────────────
        ───────────────
        ───────────────
        ───────────────
        ───────────────
        ─── C ─── ← ledger line
        ───────────────
Bass:   ───────────────
        ───────────────
        ───────────────
        ───────────────
```

## Note Values (Duration)

| Symbol | Name         | Beats   |
| ------ | ------------ | ------- |
| 𝅝      | Whole note   | 4 beats |
| 𝅗𝅥     | Half note    | 2 beats |
| ♩      | Quarter note | 1 beat  |
| ♪      | Eighth note  | ½ beat  |

## Counting

In 4/4 time (most common):

```
| 1   2   3   4   | 1   2   3   4   |
| ♩   ♩   ♩   ♩   | 𝅗𝅥       𝅗𝅥       |
| C   D   E   F   | G───────  E─────── |
```

Count "1, 2, 3, 4" steadily like a clock ticking.

## Practice Task

1. Write out the treble clef line notes (E, G, B, D, F) on paper
2. Write out the space notes (F, A, C, E)
3. On the piano, play each note as you say its name
4. Use a flashcard app or draw cards with notes — quiz yourself daily
