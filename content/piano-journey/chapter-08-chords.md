## What is a Chord?

Three or more notes played together. Chords create the **harmony** — the emotional backdrop of music.

## Major Chords (Happy Sound)

Formula: Root + 4 semitones + 3 semitones

```
C Major: C - E - G
D Major: D - F# - A
E Major: E - G# - B
F Major: F - A - C
G Major: G - B - D
A Major: A - C# - E
```

## Minor Chords (Sad Sound)

Formula: Root + 3 semitones + 4 semitones

```
C minor: C - Eb - G
D minor: D - F - A
E minor: E - G - B
A minor: A - C - E
```

## Chord Inversions

Same notes, different order (different bottom note):

```
C Major:
  Root position: C - E - G  (C on bottom)
  1st inversion: E - G - C  (E on bottom)
  2nd inversion: G - C - E  (G on bottom)
```

Inversions make chord changes smoother — less hand jumping.

## The I-IV-V-I Progression

The most common chord pattern in all of music:

```
In C Major:
  I  = C Major (C-E-G)    "home"
  IV = F Major (F-A-C)    "departure"
  V  = G Major (G-B-D)    "tension"
  I  = C Major (C-E-G)    "resolution"
```

Thousands of songs use just these three chords!

## 🎵 Songs with I-IV-V

### Let It Be (Beatles)

```
| C     | G     | Am    | F     |
| I     | V     | vi    | IV    |
```

### Stand By Me

```
| C     | C     | Am    | Am    |
| F     | G     | C     | C     |
```

### Twinkle Twinkle (Full Harmony)

```
RH melody: | C C G G | A A G - | F F E E | D D C - |
LH chords: | C       | F    C  | F       | G    C  |
```

## Accompaniment Patterns

### Pattern 1: Block Chords

```
LH: | C-E-G ─── | F-A-C ─── | G-B-D ─── | C-E-G ─── |
```

### Pattern 2: Alberti Bass

```
LH: | C G E G | C G E G | (repeat per chord)
    | 5 1 3 1 | 5 1 3 1 |
```

### Pattern 3: Oom-Pah

```
LH: | C   E-G | C   E-G | (bass note, then chord)
    | 5   3-1 | 5   3-1 |
```

### Pattern 4: Arpeggio

```
LH: | C  E  G  E | C  E  G  E |
    | 5  3  1  3 | 5  3  1  3 |
```

## Practice: Chord Progressions

Play these progressions with left hand, 4 beats per chord:

```
Progression 1: | C | F | G | C |
Progression 2: | C | Am | F | G |
Progression 3: | Am | F | C | G |  (pop progression)
Progression 4: | C | G | Am | F |  (axis of awesome)
```

Then add a simple right hand melody on top!
