# Chapter 2: Forces & Newton's Laws

## Newton's Three Laws

**1st Law (Inertia):** An object stays at rest or constant velocity unless a net force acts on it.

**2nd Law:** F_net = ma

**3rd Law:** Every action has an equal and opposite reaction (F_AB = -F_BA).

## Free Body Diagrams

```
Object on surface:        Object on incline:

     N ↑                       N ↑
     |                         | /
f ←──■──→ F              f ←──■/ θ
     |                        /|
     ↓ W=mg                  / ↓ mg

                    Components on incline:
                    Along slope: mg sinθ
                    Perpendicular: mg cosθ
```

## Common Forces

| Force    | Formula    | Direction      |
| -------- | ---------- | -------------- |
| Weight   | W = mg     | Downward       |
| Normal   | N (varies) | ⊥ to surface   |
| Friction | f = μN     | Opposes motion |
| Tension  | T (varies) | Along rope     |

## Friction

```
Static:  f_s ≤ μ_s × N  (prevents motion starting)
Kinetic: f_k = μ_k × N  (during sliding)
μ_s > μ_k always
```

## Example: Pushing a Box

20 kg box, F = 100 N horizontal, μ_k = 0.3:

```
N = mg = 196 N
f_k = 0.3(196) = 58.8 N
F_net = 100 - 58.8 = 41.2 N
a = 41.2/20 = 2.06 m/s²
```

## Atwood Machine

```
     ┌─○─┐
     │   │
   [m₁] [m₂]    m₁ > m₂

a = (m₁-m₂)g / (m₁+m₂)
T = 2m₁m₂g / (m₁+m₂)
```

## Practice Problems

**P1.** 5 kg block pulled by 30 N at 37° above horizontal (frictionless). Find acceleration.

> **Solution:**
> Fₓ = 30cos37° = 24 N
> a = 24/5 = 4.8 m/s²

**P2.** 10 kg block, μ_s = 0.5. Minimum force to start motion?

> **Solution:**
> f_s(max) = μ_s × mg = 0.5(98) = 49 N

**P3.** Atwood machine: m₁=8 kg, m₂=6 kg. Find a and T.

> **Solution:**
> a = 2(9.8)/14 = 1.4 m/s²
> T = 2(8)(6)(9.8)/14 = 67.2 N

**P4.** 3 kg block on 30° incline, μ_k=0.2, slides down. Find acceleration.

> **Solution:**
> a = g(sin30° - μ_k cos30°) = 9.8(0.5 - 0.173) = 3.2 m/s²
