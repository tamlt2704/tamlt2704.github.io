# Chapter 4: Waves & Sound

## Wave Types

**Transverse:** particles move ⊥ to wave direction (light, string)
**Longitudinal:** particles move ∥ to wave direction (sound)

```
Transverse wave:
    λ (wavelength)
|←──────────→|
  ∧       ∧
 / \     / \       → wave direction
/   \   /   \
─────\─/─────\─── equilibrium
      ∨       ∨
|A| = amplitude
```

## Wave Equation

```
v = fλ = λ/T
T = 1/f
```

| Property     | Unit |
| ------------ | ---- |
| Wavelength λ | m    |
| Frequency f  | Hz   |
| Period T     | s    |
| Speed v      | m/s  |

## Sound

Sound = longitudinal mechanical wave (needs medium)

| Medium     | Speed    |
| ---------- | -------- |
| Air (20°C) | 343 m/s  |
| Water      | 1480 m/s |
| Steel      | 5960 m/s |

Human hearing: 20 Hz – 20,000 Hz

## Doppler Effect

```
Source approaching → higher pitch (compressed waves)
Source receding → lower pitch (stretched waves)

f_obs = f_source × (v ± v_obs) / (v ∓ v_source)
```

## Standing Waves (String fixed both ends)

```
n=1: ∧         n=2: ∧   ∧      n=3: ∧ ∧ ∧
    / \             / \ / \         /\/\/\
───/───\── L    ───/───X───\──   ──/──X──X──\──

fₙ = n × v/(2L)
```

## Example: Thunder

See lightning, hear thunder 4 s later. Distance?

```
d = 343 × 4 = 1372 m ≈ 1.4 km
```

## Practice Problems

**P1.** Wave: f=500 Hz, λ=0.68 m. Speed?

> **Solution:**
> v = fλ = 500(0.68) = 340 m/s

**P2.** String L=1.2m, v=240 m/s. First 3 harmonics?

> **Solution:**
> f₁ = 240/2.4 = 100 Hz, f₂ = 200 Hz, f₃ = 300 Hz

**P3.** Ambulance (f=700 Hz) approaches at 30 m/s. Heard frequency?

> **Solution:**
> f = 700 × 343/(343-30) = 700 × 343/313 = 767 Hz

**P4.** Sonar returns in 0.4 s from ocean floor. Depth? (v=1480 m/s)

> **Solution:**
> d = 1480 × 0.2 = 296 m (one-way time = 0.2 s)
