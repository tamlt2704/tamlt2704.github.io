# Chapter 5: Electricity & Magnetism

## Electric Charge

- Two types: positive (+) and negative (-)
- Like charges repel, opposite charges attract
- Elementary charge: e = 1.6 × 10⁻¹⁹ C

## Coulomb's Law

```
F = k × |q₁q₂| / r²
k = 8.99 × 10⁹ N·m²/C²
```

```
  (+)────r────(-)
   →  F_attract  ←

  (+)────r────(+)
   ←  F_repel  →
```

## Electric Field

```
E = F/q = kQ/r²    (N/C or V/m)
```

Field lines: away from (+), toward (-)

```
  (+)              (-)
  → → →          ← ← ←
  → → →          ← ← ←
  → → →          ← ← ←
```

## Voltage (Electric Potential Difference)

```
V = W/q = Energy per unit charge
Unit: Volt (V) = J/C
```

## Current, Resistance, Ohm's Law

```
Current:    I = Q/t     (Ampere = C/s)
Resistance: R = V/I     (Ohm = V/A)
Ohm's Law:  V = IR
```

## Power in Circuits

```
P = IV = I²R = V²/R
Unit: Watt (W)
```

## Series vs Parallel Circuits

```
Series:                  Parallel:
──[R₁]──[R₂]──[R₃]──   ──┬─[R₁]─┬──
                           ├─[R₂]─┤
R_total = R₁+R₂+R₃        └─[R₃]─┘
I same everywhere        1/R_t = 1/R₁+1/R₂+1/R₃
V splits                 V same across all
                         I splits
```

## Magnetism

- Moving charges create magnetic fields
- F = qvB sinθ (force on moving charge)
- Right-hand rule for direction

## Electromagnetic Induction (Faraday's Law)

```
EMF = -N × ΔΦ/Δt
Φ = BA cosθ (magnetic flux)
```

Changing magnetic flux → induced voltage (generators, transformers)

## Example: Home Circuit

A 100W bulb on 120V supply:

```
I = P/V = 100/120 = 0.83 A
R = V/I = 120/0.83 = 144 Ω
```

## Practice Problems

**P1.** Two charges: q₁=+3μC, q₂=-5μC, r=0.2m. Force?

> **Solution:**
> F = (8.99×10⁹)(3×10⁻⁶)(5×10⁻⁶)/(0.04) = 3.37 N (attractive)

**P2.** Three resistors (4Ω, 6Ω, 12Ω) in parallel. Total resistance?

> **Solution:**
> 1/R = 1/4 + 1/6 + 1/12 = 3/12 + 2/12 + 1/12 = 6/12
> R = 2 Ω

**P3.** A 9V battery drives 0.5A through a circuit. Power dissipated?

> **Solution:**
> P = IV = 0.5(9) = 4.5 W

**P4.** An electron (v=3×10⁶ m/s) enters a B=0.5T field perpendicular. Force on it?

> **Solution:**
> F = qvB = (1.6×10⁻¹⁹)(3×10⁶)(0.5) = 2.4×10⁻¹³ N
