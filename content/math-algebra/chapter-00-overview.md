# Math: Algebra - Course Overview

## Welcome to Algebra!

Algebra is the language of mathematics — it lets us describe patterns, solve problems, and model the real world using symbols and equations.

## Course Structure

| Chapter | Topic                   | Key Skills                             |
| ------- | ----------------------- | -------------------------------------- |
| 1       | Numbers & Operations    | Number types, order of operations      |
| 2       | Variables & Expressions | Simplifying, evaluating expressions    |
| 3       | Linear Equations        | Solving one- and two-step equations    |
| 4       | Inequalities            | Solving and graphing inequalities      |
| 5       | Polynomials             | Adding, multiplying, factoring         |
| 6       | Quadratics              | Factoring, quadratic formula, graphing |
| 7       | Functions & Graphs      | Domain, range, transformations         |
| 8       | Real-World Applications | Modeling with algebra                  |

## Prerequisites

- Arithmetic (addition, subtraction, multiplication, division)
- Fractions and decimals
- Basic number sense

## How to Succeed

1. Work through examples with pencil and paper
2. Attempt problems before checking solutions
3. If stuck, re-read the relevant section
4. Practice daily — algebra is a skill built through repetition
