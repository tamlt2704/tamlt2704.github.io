# Chapter 3: Linear Equations

## What is an Equation?

An equation states two expressions are equal: `3x + 2 = 14`

**Goal:** Find the value of the variable that makes it true.

## Solving One-Step Equations

Use inverse operations:

```
x + 5 = 12  →  x = 12 - 5 = 7
x - 3 = 8   →  x = 8 + 3 = 11
4x = 20     →  x = 20/4 = 5
x/3 = 6     →  x = 6 × 3 = 18
```

## Solving Two-Step Equations

Undo addition/subtraction first, then multiplication/division.

**Example:** 3x + 7 = 22

```
3x = 22 - 7 = 15
x = 15/3 = 5
```

## Multi-Step Equations

**Example:** 2(x + 3) - 4 = 12

```
2x + 6 - 4 = 12
2x + 2 = 12
2x = 10
x = 5
```

## Variables on Both Sides

**Example:** 5x - 3 = 2x + 9

```
5x - 2x = 9 + 3
3x = 12
x = 4
```

## Special Cases

- **No solution:** 2x + 1 = 2x + 5 → 1 = 5 (contradiction)
- **Infinite solutions:** 3(x+2) = 3x + 6 → 6 = 6 (identity)

## Linear Equations in Two Variables

Standard form: Ax + By = C
Slope-intercept: y = mx + b

```
y
|    /
|   / ← slope m = rise/run
|  /
| / ← y-intercept b
|/___________x
```

### Slope Formula

```
m = (y₂ - y₁) / (x₂ - x₁)
```

## Practice Problems

**P1.** Solve: 4x - 9 = 15

> **Solution:**
> 4x = 24 → x = 6

**P2.** Solve: 3(2x - 1) = 4x + 7

> **Solution:**
> 6x - 3 = 4x + 7 → 2x = 10 → x = 5

**P3.** Find slope between (2, 3) and (6, 11).

> **Solution:**
> m = (11-3)/(6-2) = 8/4 = 2

**P4.** Write equation of line with slope 3, y-intercept -2.

> **Solution:**
> y = 3x - 2
