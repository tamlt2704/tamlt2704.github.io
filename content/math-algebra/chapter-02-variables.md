# Chapter 2: Variables & Expressions

## What is a Variable?

A variable is a letter representing an unknown value: x, y, n, etc.

## Algebraic Expressions

An expression combines numbers, variables, and operations:

```
3x + 5      2a² - 4a + 1      (x+y)/2
```

### Terms, Coefficients, Constants

In `4x² + 3x - 7`:

- Terms: 4x², 3x, -7
- Coefficients: 4, 3
- Constant: -7

## Evaluating Expressions

Substitute values and compute.

**Example:** Evaluate 2x² - 3x + 1 when x = 4

```
= 2(16) - 3(4) + 1 = 32 - 12 + 1 = 21
```

## Combining Like Terms

Like terms have the same variable and exponent.

```
5x + 3x = 8x
4a² + 2a - a² + 5a = 3a² + 7a
```

## Distributive Property

```
a(b + c) = ab + ac

3(2x + 4) = 6x + 12
-2(x - 5) = -2x + 10
```

## Simplifying Expressions

**Example:** Simplify 2(3x + 1) - 4(x - 2)

```
= 6x + 2 - 4x + 8
= 2x + 10
```

## Translating Words to Algebra

| Phrase                  | Expression |
| ----------------------- | ---------- |
| 5 more than x           | x + 5      |
| 3 less than y           | y - 3      |
| twice a number          | 2n         |
| product of a and b      | ab         |
| quotient of x and 4     | x/4        |
| a number squared plus 3 | n² + 3     |

## Practice Problems

**P1.** Evaluate 3a - 2b when a=5, b=3.

> **Solution:**
> = 3(5) - 2(3) = 15 - 6 = 9

**P2.** Simplify: 7x - 2 + 3x + 8

> **Solution:**
> = 10x + 6

**P3.** Expand and simplify: 4(2x - 3) + 5(x + 1)

> **Solution:**
> = 8x - 12 + 5x + 5 = 13x - 7

**P4.** Write an expression: "Six less than triple a number"

> **Solution:**
> 3n - 6
