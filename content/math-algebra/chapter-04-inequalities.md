# Chapter 4: Inequalities

## Inequality Symbols

```
<   less than
>   greater than
≤   less than or equal to
≥   greater than or equal to
≠   not equal to
```

## Solving Inequalities

Same rules as equations, **except**: flip the sign when multiplying/dividing by a negative.

**Example 1:** 2x + 3 < 11

```
2x < 8
x < 4
```

**Example 2:** -3x ≥ 12

```
x ≤ -4    ← sign flipped!
```

## Graphing on a Number Line

```
x < 4:     ←─────────○         (open circle, not included)
                      4

x ≥ -2:         ●─────────→    (closed circle, included)
                -2
```

## Compound Inequalities

**AND (intersection):** both must be true

```
-3 < x ≤ 5:    ○────────●
               -3        5
```

**OR (union):** at least one true

```
x < -1 OR x > 3:  ←──○     ○──→
                      -1    3
```

## Solving Compound Inequalities

**Example:** -2 ≤ 3x + 1 < 10

```
Subtract 1:  -3 ≤ 3x < 9
Divide by 3: -1 ≤ x < 3
```

## Absolute Value Inequalities

```
|x| < a  →  -a < x < a     (AND)
|x| > a  →  x < -a OR x > a  (OR)
```

**Example:** |2x - 1| ≤ 5

```
-5 ≤ 2x - 1 ≤ 5
-4 ≤ 2x ≤ 6
-2 ≤ x ≤ 3
```

## Systems of Inequalities (Graphing)

Solution is the overlapping shaded region.

```
y ≤ x + 2  and  y > -x + 1

y
|  /  ← y=x+2
| /  ///  ← shaded overlap region
|/ ///
|////
+──\──── x
    \ ← y=-x+1
```

## Practice Problems

**P1.** Solve: 5x - 7 > 13

> **Solution:**
> 5x > 20 → x > 4

**P2.** Solve: -4x + 2 ≤ 18

> **Solution:**
> -4x ≤ 16 → x ≥ -4 (flip sign)

**P3.** Solve: |x + 3| < 7

> **Solution:**
> -7 < x + 3 < 7 → -10 < x < 4

**P4.** Solve: 1 < 2x - 3 ≤ 9

> **Solution:**
> 4 < 2x ≤ 12 → 2 < x ≤ 6
