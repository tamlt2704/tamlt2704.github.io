# Chapter 1: Numbers & Operations

## Number Types

```
Natural numbers (ℕ):    1, 2, 3, 4, ...
Whole numbers (W):      0, 1, 2, 3, ...
Integers (ℤ):          ..., -2, -1, 0, 1, 2, ...
Rational (ℚ):          fractions p/q (q≠0): ½, -3, 0.75
Irrational:            √2, π, e (non-repeating decimals)
Real numbers (ℝ):      All of the above
```

## Order of Operations (PEMDAS)

```
P - Parentheses first
E - Exponents
M/D - Multiplication & Division (left to right)
A/S - Addition & Subtraction (left to right)
```

### Worked Example

```
3 + 2 × (8 - 3)² ÷ 5
= 3 + 2 × (5)² ÷ 5      ← parentheses
= 3 + 2 × 25 ÷ 5        ← exponent
= 3 + 50 ÷ 5            ← multiply
= 3 + 10                 ← divide
= 13                     ← add
```

## Properties of Operations

| Property     | Addition          | Multiplication |
| ------------ | ----------------- | -------------- |
| Commutative  | a+b = b+a         | ab = ba        |
| Associative  | (a+b)+c = a+(b+c) | (ab)c = a(bc)  |
| Identity     | a+0 = a           | a×1 = a        |
| Inverse      | a+(-a) = 0        | a×(1/a) = 1    |
| Distributive | a(b+c) = ab + ac  |                |

## Absolute Value

|x| = distance from zero (always ≥ 0)

```
|5| = 5,  |-3| = 3,  |0| = 0
```

## Exponent Rules

```
aᵐ × aⁿ = aᵐ⁺ⁿ
aᵐ ÷ aⁿ = aᵐ⁻ⁿ
(aᵐ)ⁿ = aᵐⁿ
a⁰ = 1
a⁻ⁿ = 1/aⁿ
```

## Practice Problems

**P1.** Evaluate: 4 × 3² - 2(5 + 1)

> **Solution:**
> = 4 × 9 - 2(6) = 36 - 12 = 24

**P2.** Simplify: 2³ × 2⁴

> **Solution:**
> = 2⁷ = 128

**P3.** Evaluate: |4 - 9| + |-2|

> **Solution:**
> = |-5| + 2 = 5 + 2 = 7

**P4.** Simplify: (3²)³ ÷ 3⁴

> **Solution:**
> = 3⁶ ÷ 3⁴ = 3² = 9
