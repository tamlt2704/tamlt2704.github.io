# Chapter 6: Quadratics & Functions

## Quadratic Equations

Standard form: ax² + bx + c = 0 (a ≠ 0)

### Solving by Factoring

```
x² - 5x + 6 = 0 → (x-2)(x-3) = 0 → x = 2 or x = 3
```

### Quadratic Formula

```
x = (-b ± √(b² - 4ac)) / 2a
```

### Discriminant: D = b² - 4ac

- D > 0: two real solutions
- D = 0: one repeated root
- D < 0: no real solutions

### Graphing Parabolas

```
y = ax² + bx + c
Vertex: x = -b/(2a)
a > 0: opens up ∪    a < 0: opens down ∩

y
|*         *
| *       *
|  * * *      ← vertex
+──────────x
```

## Functions

A function assigns exactly one output per input: f(x) = 2x + 3

**Vertical Line Test:** crosses graph at most once → it's a function.

### Domain & Range

- Domain: valid inputs (x-values)
- Range: possible outputs (y-values)

### Types of Functions

```
Linear:      f(x) = mx + b     (straight line)
Quadratic:   f(x) = ax² + bx + c  (parabola)
Absolute:    f(x) = |x|        (V-shape)
Exponential: f(x) = aˣ         (rapid growth/decay)
```

### Transformations of y = f(x)

| Change     | Effect              |
| ---------- | ------------------- |
| f(x) + k   | Shift up k          |
| f(x - h)   | Shift right h       |
| -f(x)      | Reflect over x-axis |
| af(x), a>1 | Vertical stretch    |

### Inverse Functions

Swap x and y, solve for y:

```
f(x) = 3x - 6 → f⁻¹(x) = (x+6)/3
```

## Practice Problems

**P1.** Solve: x² - 7x + 10 = 0

> **Solution:**
> (x-5)(x-2) = 0 → x = 5 or x = 2

**P2.** Use quadratic formula: 3x² - 2x - 1 = 0

> **Solution:**
> x = (2 ± √(4+12))/6 = (2±4)/6 → x = 1 or x = -1/3

**P3.** Find vertex of y = x² + 8x + 12

> **Solution:**
> x = -8/2 = -4, y = 16-32+12 = -4. Vertex: (-4, -4)

**P4.** f(x) = x² - 4x. Find f(5).

> **Solution:**
> f(5) = 25 - 20 = 5

**P5.** Find domain of f(x) = √(x-3)

> **Solution:**
> x - 3 ≥ 0 → Domain: x ≥ 3, or [3, ∞)

**P6.** Find inverse of f(x) = (x-2)/5

> **Solution:**
> x = (y-2)/5 → y = 5x + 2 → f⁻¹(x) = 5x + 2
