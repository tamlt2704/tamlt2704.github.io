# Chapter 5: Polynomials

## What is a Polynomial?

A sum of terms with variables raised to whole-number exponents.

```
3x⁴ - 2x² + x - 7
```

- **Degree**: highest exponent (4 in example above)
- **Monomial**: 1 term, **Binomial**: 2 terms, **Trinomial**: 3 terms

## Adding & Subtracting Polynomials

Combine like terms:

```
(3x² + 2x - 1) + (x² - 4x + 5)
= 4x² - 2x + 4

(5x² - 3x + 2) - (2x² + x - 4)
= 5x² - 3x + 2 - 2x² - x + 4
= 3x² - 4x + 6
```

## Multiplying Polynomials

### Monomial × Polynomial

```
3x(2x² - 4x + 1) = 6x³ - 12x² + 3x
```

### Binomial × Binomial (FOIL)

```
(x + 3)(x - 5)
= x² - 5x + 3x - 15
= x² - 2x - 15

F: x·x    O: x·(-5)    I: 3·x    L: 3·(-5)
```

### Special Products

```
(a + b)² = a² + 2ab + b²
(a - b)² = a² - 2ab + b²
(a + b)(a - b) = a² - b²   (difference of squares)
```

## Factoring

### Greatest Common Factor (GCF)

```
6x³ + 9x² = 3x²(2x + 3)
```

### Factoring Trinomials (x² + bx + c)

Find two numbers that multiply to c and add to b:

```
x² + 7x + 12 = (x + 3)(x + 4)    [3×4=12, 3+4=7]
x² - 2x - 15 = (x - 5)(x + 3)    [-5×3=-15, -5+3=-2]
```

### Difference of Squares

```
x² - 49 = (x + 7)(x - 7)
4x² - 9 = (2x + 3)(2x - 3)
```

## Polynomial Division

```
(x² + 5x + 6) ÷ (x + 2)

     x + 3
    ─────────
x+2 │ x² + 5x + 6
      x² + 2x
      ───────
          3x + 6
          3x + 6
          ───────
              0

Answer: x + 3
```

## Practice Problems

**P1.** Multiply: (2x - 3)(x + 4)

> **Solution:**
> = 2x² + 8x - 3x - 12 = 2x² + 5x - 12

**P2.** Factor: x² - 5x - 14

> **Solution:**
> Find numbers: multiply to -14, add to -5 → -7 and +2
> = (x - 7)(x + 2)

**P3.** Factor completely: 3x³ - 12x

> **Solution:**
> = 3x(x² - 4) = 3x(x+2)(x-2)

**P4.** Expand: (3x - 2)²

> **Solution:**
> = 9x² - 12x + 4
