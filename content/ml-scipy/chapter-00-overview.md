# Machine Learning with Scikit-Learn & SciPy

This series covers practical machine learning using Python's scientific computing stack. Each chapter builds on the previous, progressing from fundamentals to end-to-end projects.

## Prerequisites

- Python 3.9+
- Basic linear algebra (vectors, matrices)
- Basic calculus (derivatives, chain rule)

## Setup

```bash
pip install numpy scipy scikit-learn matplotlib pandas
```

## Philosophy

Each chapter includes:

- **Mathematical intuition** — understand _why_ algorithms work
- **Code from scratch** — implement core logic with NumPy/SciPy
- **Scikit-learn usage** — leverage production-ready implementations
- **Practical examples** — real datasets, real problems
