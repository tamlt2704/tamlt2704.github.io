# Chapter 7: Organic Chemistry Introduction

## What is Organic Chemistry?

The study of carbon-containing compounds. Carbon is special because it forms 4 bonds and can create long chains and rings.

## Hydrocarbons

### Alkanes (Single bonds, CₙH₂ₙ₊₂)

```
Methane:  CH₄       Ethane: C₂H₆      Propane: C₃H₈

    H                H   H             H   H   H
    |                |   |             |   |   |
H ─ C ─ H       H ─ C ─ C ─ H    H ─ C ─ C ─ C ─ H
    |                |   |             |   |   |
    H                H   H             H   H   H
```

### Alkenes (Double bond, CₙH₂ₙ)

```
Ethene (ethylene): H₂C═CH₂
```

### Alkynes (Triple bond, CₙH₂ₙ₋₂)

```
Ethyne (acetylene): HC≡CH
```

## Isomers

Same formula, different structure:

```
C₄H₁₀ has two isomers:

Butane:          Isobutane (2-methylpropane):
C─C─C─C              C
                      |
                  C ─ C ─ C
```

## Functional Groups

| Group | Name               | Example               | Found in            |
| ----- | ------------------ | --------------------- | ------------------- |
| -OH   | Hydroxyl (alcohol) | CH₃OH (methanol)      | Drinks, fuel        |
| -COOH | Carboxyl (acid)    | CH₃COOH (acetic acid) | Vinegar             |
| -NH₂  | Amino              | CH₃NH₂                | Proteins            |
| C=O   | Carbonyl (ketone)  | CH₃COCH₃ (acetone)    | Nail polish remover |
| -CHO  | Aldehyde           | HCHO (formaldehyde)   | Preservative        |

## Polymers

Repeating units (monomers) linked together:

```
n(CH₂═CH₂) → ─[CH₂─CH₂]ₙ─
 ethylene       polyethylene (plastic bags)
```

## Organic Reactions (Basic)

**Combustion:**

```
CH₄ + 2O₂ → CO₂ + 2H₂O + energy
```

**Addition (alkenes):**

```
CH₂═CH₂ + H₂ → CH₃─CH₃  (hydrogenation)
```

## Practice Problems

**P1.** Name: CH₃CH₂CH₂CH₂CH₃

> **Solution:**
> 5 carbons, all single bonds → Pentane

**P2.** Draw structural formula for propene.

> **Solution:**
> CH₂═CH─CH₃ (or H₂C=CHCH₃)
> Double bond between C1 and C2, 3 carbons total

**P3.** What functional group is in CH₃CH₂OH?

> **Solution:**
> -OH → Hydroxyl group → This is an alcohol (ethanol)

**P4.** Write balanced combustion of C₂H₆.

> **Solution:**
> 2C₂H₆ + 7O₂ → 4CO₂ + 6H₂O
