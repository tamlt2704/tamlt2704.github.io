# Chapter 3: Chemical Bonds

## Why Do Atoms Bond?

Atoms bond to achieve a stable electron configuration (full outer shell — octet rule).

## Types of Bonds

### Ionic Bonds (Metal + Nonmetal)

Transfer of electrons:

```
Na (2,8,1) → Na⁺ (2,8) + e⁻
Cl (2,8,7) + e⁻ → Cl⁻ (2,8,8)

Na⁺ ←→ Cl⁻  (electrostatic attraction)
```

Properties: high melting point, conduct when dissolved, crystalline

### Covalent Bonds (Nonmetal + Nonmetal)

Sharing of electrons:

```
H─H     Single bond (2 shared e⁻)
O═O     Double bond (4 shared e⁻)
N≡N     Triple bond (6 shared e⁻)
```

### Metallic Bonds (Metal + Metal)

"Sea of electrons" model:

```
⊕  ⊕  ⊕  ⊕
  e⁻ e⁻ e⁻
⊕  ⊕  ⊕  ⊕    (delocalized electrons)
  e⁻ e⁻ e⁻
⊕  ⊕  ⊕  ⊕
```

Properties: conduct electricity, malleable, lustrous

## Electronegativity & Bond Polarity

```
ΔEN = 0:       Nonpolar covalent (H₂, O₂)
0 < ΔEN < 1.7: Polar covalent (H₂O, HCl)
ΔEN > 1.7:     Ionic (NaCl, MgO)
```

```
Polar bond:  δ⁺ H ─── Cl δ⁻
             (partial charges)
```

## Practice Problems

**P1.** What type of bond forms between Mg and O?

> **Solution:**
> Ionic — Mg is a metal, O is a nonmetal. Mg loses 2e⁻ → Mg²⁺, O gains 2e⁻ → O²⁻

**P3.** Is HF polar or nonpolar?

> **Solution:**
> Polar — F is much more electronegative than H (ΔEN ≈ 1.9)

**P4.** Predict shape of CCl₄.

> **Solution:**
> 4 bonding pairs, 0 lone pairs → Tetrahedral (109.5°)
> Despite polar C-Cl bonds, molecule is nonpolar (symmetric)
