## What Does 3x Mean?

Before we solve new equations, let's make sure we understand multiplication in algebra.

`3x` means **3 groups of x**. Or: **3 × x**.

```
    3x means:

    ┌───┐   ┌───┐   ┌───┐
    │ x │ + │ x │ + │ x │  =  3 groups of x
    └───┘   └───┘   └───┘
```

If x = 5, then 3x = 3 × 5 = 15. That's 5 + 5 + 5.

Think of it like bags of candy:
- `3x` = 3 bags, each with x candies inside
- `5x` = 5 bags, each with x candies inside
- `1x` = just x (one bag — we usually just write "x")

## Solving Multiplication Equations

**Problem:** 3x = 15

This says: "3 groups of x equals 15." To find ONE group, we divide both sides by 3.

```
    3x = 15

    3x ÷ 3 = 15 ÷ 3     ← divide both sides by 3

    x = 5 ✓
```

Check: 3 × 5 = 15? Yes!

**The rule:** If x is multiplied by a number, **divide** both sides by that number.

**Example 1:** 5x = 40
```
    5x = 40
    5x ÷ 5 = 40 ÷ 5     ← divide both sides by 5
    x = 8 ✓
```

**Example 2:** 2x = 14
```
    2x = 14
    2x ÷ 2 = 14 ÷ 2     ← divide both sides by 2
    x = 7 ✓
```

**Example 3:** 10x = 60
```
    10x = 60
    10x ÷ 10 = 60 ÷ 10   ← divide both sides by 10
    x = 6 ✓
```

## Solving Division Equations

**Problem:** x/4 = 5

This says: "x split into 4 equal parts gives 5." To find the whole thing, multiply both sides by 4.

```
    x/4 = 5

    (x/4) × 4 = 5 × 4    ← multiply both sides by 4

    x = 20 ✓
```

Check: 20 ÷ 4 = 5? Yes!

**The rule:** If x is divided by a number, **multiply** both sides by that number.

**Example 1:** x/3 = 7
```
    x/3 = 7
    (x/3) × 3 = 7 × 3    ← multiply both sides by 3
    x = 21 ✓
```

**Example 2:** x/6 = 2
```
    x/6 = 2
    (x/6) × 6 = 2 × 6    ← multiply both sides by 6
    x = 12 ✓
```

## The Complete Opposite Operations Table

Now you know all four inverse operations:

| To undo... | Do the opposite... |
|---|---|
| + 5 | - 5 |
| - 3 | + 3 |
| × 4 (or 4x) | ÷ 4 |
| ÷ 6 (or x/6) | × 6 |

> "See the pattern?" Professor Zap grins. "Addition undoes subtraction. Multiplication undoes division. They're like magical opposites — each one cancels the other out!"

## Quest Challenge 🏆

A traveling merchant offers you a deal:

> "I have 5 identical treasure chests. Together, they contain 45 gold coins total. But I'll sell you just ONE chest. How many coins are in each chest?"

Set up the equation and solve it!

<details>
<summary>Solution</summary>

Let x = coins in one chest.

5x = 45 (5 chests × coins per chest = 45 total)
x = 9

Each chest has **9 gold coins**. Worth the purchase? That's up to you, adventurer!

</details>

## Level Up! 📈

What you learned:
- `3x` means "3 groups of x" or "3 times x"
- To undo multiplication, **divide** both sides by the same number
- To undo division, **multiply** both sides by the same number
- Multiplication and division are inverse operations (opposites)
- You now know how to solve equations with +, -, ×, and ÷

## Did You Know? 🌟

The × symbol for multiplication was invented in 1631, but algebra avoids it because it looks like the letter x. Instead, algebra uses:
- A dot: 3 · x
- Parentheses: 3(x)
- Or just smooshing: 3x

All three mean the same thing: 3 times x. Mathematicians are surprisingly lazy about writing things out!
