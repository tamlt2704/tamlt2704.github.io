## The Quest

You and Professor Zap arrive at the **Treasure Map Tower**. Inside, there's a map on the wall — but parts of it are covered by locked boxes. Each box has a letter on it: x, y, n. To reveal the full map, you need to understand what these boxes mean.

> "Every locked box in Numeria contains a number," says Professor Zap. "We don't always know *which* number yet — that's the mystery! But we can still talk about the box, do math with it, and eventually figure out what's inside."

## Variables: The Mystery Boxes

A **variable** is just a letter that stands for a number you don't know yet.

```
    ┌─────┐
    │  x  │  ← This box contains a number.
    └─────┘     We just don't know which one yet.
```

Think of it like a wrapped present. You know something is inside. You just haven't opened it yet.

Common variable names:
- **x** — the most popular (the "star" of algebra)
- **y** — x's best friend
- **n** — often used for "some number"
- **a, b, c** — used when you have several unknowns

But you can use ANY letter. Even 🐱 if you want (though your teacher might give you a look).

## Writing Expressions

An **expression** is a math phrase that includes variables. It's like a recipe that says "take the mystery number and do something to it."

| Expression | What it means | In words |
|---|---|---|
| x + 3 | mystery number plus 3 | "3 more than x" |
| 2 × n | 2 times the mystery number | "double n" |
| y - 5 | mystery number minus 5 | "5 less than y" |
| x + x | mystery number plus itself | "x doubled" |

**Shortcut alert!** In algebra, we write multiplication without the × sign:
- `2 × n` becomes just `2n`
- `3 × x` becomes `3x`
- `5 × y` becomes `5y`

Why? Because × looks too much like the letter x. Confusing! So mathematicians just smoosh the number and letter together.

> "Think of `3x` as '3 groups of x,'" says Professor Zap. "Like 3 bags of candy — each bag has the same mystery amount inside."

## Evaluating Expressions

**Evaluating** means: "if I tell you what's in the box, what does the whole expression equal?"

**Example 1:** If x = 4, what is x + 3?
```
  x + 3
  = 4 + 3      ← replace x with 4
  = 7           ← do the math
```

**Example 2:** If n = 5, what is 2n?
```
  2n
  = 2 × 5      ← replace n with 5
  = 10          ← do the math
```

**Example 3:** If y = 10, what is y - 3?
```
  y - 3
  = 10 - 3     ← replace y with 10
  = 7           ← do the math
```

**Example 4:** If x = 6, what is 3x + 1?
```
  3x + 1
  = 3(6) + 1   ← replace x with 6
  = 18 + 1     ← multiply first
  = 19          ← then add
```

## The Treasure Map Quest 🗺️

Professor Zap points to the map on the wall:

> "The map uses variables as coordinates! Each box tells you how many steps to take. Let me decode the first clue for you."

The map says:

```
╔═══════════════════════════════════════╗
║  Start at the Old Oak Tree.           ║
║  Walk x steps East, where x = 6.     ║
║  Then walk 2x steps North.           ║
║  The treasure is y steps West,        ║
║  where y = x - 2.                    ║
╚═══════════════════════════════════════╝
```

Let's decode it:
- Walk **x = 6** steps East → 6 steps East ✓
- Walk **2x** steps North → 2 × 6 = **12** steps North ✓
- y = x - 2 = 6 - 2 = **4**, so walk **4** steps West ✓

You follow the directions and find... a small golden key! It'll come in handy later.

## Quest Challenge 🏆

The second part of the map is trickier:

```
╔═══════════════════════════════════════╗
║  From the Golden Fountain:            ║
║  n = 7                                ║
║  Walk n + 3 steps South.              ║
║  Walk 2n - 4 steps East.             ║
║  Walk n × n steps... just kidding.    ║
║  (Professor Zap wrote that as a joke) ║
║  The real last step: walk 3 steps up. ║
╚═══════════════════════════════════════╝
```

How many steps South? How many steps East?

<details>
<summary>Solution</summary>

- n = 7
- South: n + 3 = 7 + 3 = **10 steps**
- East: 2n - 4 = 2(7) - 4 = 14 - 4 = **10 steps**
- (And yes, n × n = 49 steps would be exhausting. Thanks, Professor Zap. 😅)

</details>

## Level Up! 📈

What you learned:
- A **variable** is a letter that represents an unknown number
- An **expression** is a math phrase with variables (like 3x + 1)
- **Evaluating** means plugging in a number for the variable
- `2n` means "2 times n" — we skip the × sign in algebra
- Variables can represent different numbers in different problems

## Did You Know? 🌟

The letter **x** became the go-to variable because of a printing accident! When a French math book was being printed in the 1600s, the printer ran out of letters and used "x" as a substitute for the unknown. It stuck, and now x is the most famous letter in all of mathematics.
