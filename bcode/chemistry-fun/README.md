# Chemistry Fun — From Atoms to Explosions

A narrative-driven chemistry course where every concept is a kitchen experiment, a simulation, or a "why does this happen?" moment. You're a curious inventor at **MoleCraft Labs**, a startup making educational chemistry kits. Each chapter is a product you're designing — and you need to understand the science to make it safe and spectacular.

## Prerequisites

- Curiosity and a kitchen
- Python 3.10+ (for simulations, optional)
- No lab equipment required (all experiments use household items)

## Philosophy

Every chemistry concept is introduced because a product doesn't work without understanding it. You'll see the failed experiment first, then learn the science that explains it. The mystery comes first. The explanation follows.
