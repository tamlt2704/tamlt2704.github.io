# Teach Your Kids to Code — A Parent's Playbook

A course for developer-parents who want to introduce programming to their children (ages 6-14) without making it feel like school. Each chapter is a 30-minute activity you do together — no lectures, no homework, just building cool stuff.

## Prerequisites

- A computer (any OS)
- Patience (they'll get frustrated — that's normal)
- No teaching experience needed

## Philosophy

Follow their interest, not a curriculum. If they love Minecraft, start with mods. If they love art, start with Scratch animations. If they love math, start with Python patterns. The goal isn't to make them programmers — it's to show them that computers do what YOU tell them to do. That's power. That's magic. That's enough.
