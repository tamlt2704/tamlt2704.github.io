## The Problem

LaunchPad's finance team receives invoices from vendors as PDF email attachments. Every week, someone opens each PDF, reads the vendor name, amount, and due date, then types it into a spreadsheet. It takes 2 hours every Friday.

The finance lead: "We get 30-40 invoices a week. I'm spending half a day on data entry. And I still make typos."

The invoices arrive at invoices@launchpad.io. They're PDFs — some are structured (generated by accounting software), some are scanned images. You need to:
1. Detect new emails with PDF attachments
2. Extract text from the PDFs
3. Parse the relevant fields (vendor, amount, due date)
4. Store the data in Postgres
5. Upload the original PDF to S3 for archival

## Email Trigger: Watching for Invoices

### IMAP Email Trigger

```json
{
  "parameters": {
    "mailbox": "INBOX",
    "options": {
      "customEmailConfig": {
        "host": "imap.gmail.com",
        "port": 993,
        "secure": true
      }
    },
    "filters": {
      "to": "invoices@launchpad.io",
      "hasAttachment": true
    }
  },
  "name": "New Invoice Email",
  "type": "n8n-nodes-base.imapEmail",
  "position": [250, 300]
}
```

The IMAP trigger polls for new emails. When it finds one with an attachment, it outputs:

```json
{
  "from": "billing@vendor.com",
  "subject": "Invoice #4521 - January 2024",
  "text": "Please find attached...",
  "attachments": [
    {
      "filename": "invoice-4521.pdf",
      "contentType": "application/pdf",
      "content": "<base64 encoded data>"
    }
  ]
}
```

## Reading and Parsing Files

### CSV Files

For CSV attachments, use the **Spreadsheet File** node:

```json
{
  "parameters": {
    "operation": "fromFile",
    "fileFormat": "csv",
    "options": {
      "headerRow": true,
      "delimiter": ","
    }
  },
  "name": "Parse CSV",
  "type": "n8n-nodes-base.spreadsheetFile",
  "position": [450, 300]
}
```

Input: a binary file (CSV)
Output: array of JSON objects (one per row)

```json
[
  { "vendor": "Acme Corp", "amount": "1500.00", "due_date": "2024-02-15" },
  { "vendor": "CloudHost", "amount": "899.99", "due_date": "2024-02-01" }
]
```

### PDF Text Extraction

For text-based PDFs, use the **Extract from File** node:

```json
{
  "parameters": {
    "operation": "text",
    "options": {}
  },
  "name": "Extract PDF Text",
  "type": "n8n-nodes-base.extractFromFile",
  "position": [450, 300]
}
```

This extracts raw text from the PDF. The output is unstructured — you'll need to parse it.

### Parsing PDF Text with AI

Raw PDF text is messy. Use an LLM to extract structured data:

```javascript
// The extracted text goes to OpenAI for parsing
{
  "model": "gpt-4o-mini",
  "messages": [
    {
      "role": "system",
      "content": "Extract invoice details from the text. Return JSON: {\"vendor\": \"...\", \"invoice_number\": \"...\", \"amount\": 0.00, \"currency\": \"USD\", \"due_date\": \"YYYY-MM-DD\", \"line_items\": [{\"description\": \"...\", \"amount\": 0.00}]}"
    },
    {
      "role": "user",
      "content": "={{ $json.text }}"
    }
  ],
  "options": { "temperature": 0, "responseFormat": "json_object" }
}
```

## Uploading to S3

Archive the original PDF to S3 for compliance and retrieval:

```json
{
  "parameters": {
    "operation": "upload",
    "bucketName": "launchpad-invoices",
    "fileName": "={{ `${new Date().getFullYear()}/${new Date().getMonth()+1}/${$json.invoice_number}.pdf` }}",
    "binaryPropertyName": "attachment_0"
  },
  "name": "Upload to S3",
  "type": "n8n-nodes-base.s3",
  "position": [850, 300]
}
```

The file path includes year/month for organization: `2024/1/INV-4521.pdf`

## Working with Binary Data

n8n separates JSON data and binary data. Files (PDFs, images, CSVs) flow as binary alongside the JSON metadata.

### Key Concepts

| Concept | Meaning |
|---|---|
| `binaryPropertyName` | The key that holds the file (e.g., `data`, `attachment_0`) |
| `$binary` | Access binary metadata in expressions |
| Move Binary Data node | Convert between binary and JSON (base64) |

### Checking Binary Data Exists

```javascript
// Expression to check if a file is attached
{{ $binary?.data ? 'has file' : 'no file' }}

// Get filename
{{ $binary.data.fileName }}

// Get MIME type
{{ $binary.data.mimeType }}
```

### Converting Binary to Base64 (for API calls)

Some APIs expect base64-encoded files. Use the Code node:

```javascript
const binaryData = await this.helpers.getBinaryDataBuffer(0, 'data');
const base64 = binaryData.toString('base64');

return {
  json: {
    file_content: base64,
    filename: $input.item.binary.data.fileName
  }
};
```

## Writing Files

### Generate a CSV Report

```javascript
// Code node — build CSV content
const items = $input.all();
const headers = 'vendor,amount,due_date,status\n';
const rows = items.map(i => 
  `${i.json.vendor},${i.json.amount},${i.json.due_date},${i.json.status}`
).join('\n');

const csvContent = headers + rows;

return [{
  json: {},
  binary: {
    data: await this.helpers.prepareBinaryData(
      Buffer.from(csvContent),
      'invoice-report.csv',
      'text/csv'
    )
  }
}];
```

## Common Patterns

### Multiple Attachments

Emails can have multiple attachments. They appear as `attachment_0`, `attachment_1`, etc. Process each:

```javascript
const attachments = Object.keys($input.item.binary || {});
return attachments.map(key => ({
  json: { attachmentKey: key, filename: $input.item.binary[key].fileName },
  binary: { data: $input.item.binary[key] }
}));
```

### File Type Routing

```
[Email Trigger] → [Switch by MIME type]
    ├── application/pdf → [PDF pipeline]
    ├── text/csv → [CSV pipeline]
    └── image/* → [OCR pipeline]
```

## What You Learned

- **Email triggers** (IMAP) watch for new messages with attachments
- **Extract from File** pulls text from PDFs
- **Spreadsheet File node** parses CSVs into JSON arrays
- **AI extraction** turns unstructured PDF text into structured data
- **S3 upload** archives original files with organized paths
- **Binary data** flows alongside JSON — accessed via `$binary`
- **File generation** — build CSVs or reports in Code nodes, attach to emails

The finance team's 2-hour Friday ritual is now automated. Invoices are parsed, stored, and archived within minutes of arrival. The finance lead reviews a clean database instead of squinting at PDFs.

But there's a catch. Some invoices are over $10,000. Diana: "Anything over $10K needs my approval before we pay it. Don't just auto-process everything." You need human-in-the-loop approval.
