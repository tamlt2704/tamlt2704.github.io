# Godot for Parents — Make Games With Your Kids

A course for developer-parents who want to build games with their children. You're not learning Godot to ship on Steam — you're learning it so Saturday mornings become "let's add a new level to OUR game." Your kids design the characters, you write the code, and everyone plays the result.

## Episodes

| # | Title | The Saturday Project | What You Learn |
|---|---|---|---|
| 00 | [Before You Start](chapter-00-overview.md) | — | Install Godot, the editor, the plan |
| 01 | [Moving a Character](chapter-01-movement.md) | Kid draws a character, you make it move | Scenes, nodes, GDScript basics, input |
| 02 | [Collecting Coins](chapter-02-collectibles.md) | Kid designs coins, score goes up | Area2D, signals, UI labels |
| 03 | [Enemies That Chase](chapter-03-enemies.md) | Kid draws a monster, it follows the player | Navigation, simple AI, collision |
| 04 | [Levels and Doors](chapter-04-levels.md) | Kid draws a map on paper, you build it | TileMaps, scene transitions, doors |
| 05 | [Sound and Music](chapter-05-audio.md) | Kid picks sounds, records voice effects | AudioStreamPlayer, sound triggers |
| 06 | [Power-Ups](chapter-06-powerups.md) | Kid invents a power (fly? shrink? speed?) | Timers, state changes, particle effects |
| 07 | [Boss Fight](chapter-07-boss.md) | Kid designs the boss, you code the patterns | State machines, health bars, phases |
| 08 | [Polish and Ship](chapter-08-ship.md) | Export and play on the family tablet | Screen shake, juice, export to Android/web |

## Prerequisites

- Godot 4.x (free, open source, 50MB download)
- A kid (ages 5-12 work great) with crayons/markers
- A scanner or phone camera (to photograph kid art)
- No game dev experience needed

## Philosophy

The kid is the creative director. They decide what the game looks like, what the enemies do, what power-ups exist. You're the engineer who makes it real. The game doesn't need to be good — it needs to be THEIRS.
