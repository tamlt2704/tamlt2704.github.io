# Stock Strategy with Python — From Data to Decisions

A practical course on reading stock market data, analyzing it, backtesting strategies, and building a personal trading dashboard — all with Python. You're not trying to beat Wall Street. You're trying to make informed, data-driven decisions about your own portfolio.

## Prerequisites

- Python 3.10+
- `pip install yfinance pandas matplotlib plotly`
- Basic Python (DataFrames, plotting)
- NO finance background needed

## Philosophy

This is NOT a "get rich quick" course. The stock market is not a casino and it's not free money. This course teaches you to:
1. Read data instead of listening to hype
2. Test ideas on history before risking real money
3. Manage risk so one bad trade doesn't ruin you
4. Make decisions based on numbers, not emotions

**Disclaimer:** This is educational. Not financial advice. Past performance doesn't guarantee future results. Never invest money you can't afford to lose.
