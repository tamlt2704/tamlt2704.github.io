# Personal Finance with Code — Automate Your Money

A course for developers who want to use their coding skills to manage family finances — budgeting, investing, tax optimization, and financial independence calculations. No spreadsheets. Python scripts that actually run.

## Prerequisites

- Python 3.10+
- Basic understanding of your own finances (bank accounts, income, expenses)
- No finance background needed

## Philosophy

Developers have a superpower: we can automate repetitive analysis. Instead of checking Mint once a month, build a script that runs daily and alerts you when something's off. Your money decisions should be data-driven, not emotional. Code is the tool.
