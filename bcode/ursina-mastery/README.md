# Ursina Mastery — 3D Games in Python, The Easy Way

A narrative-driven course on Ursina, the friendliest Python 3D engine. You're building a small 3D game — from a spinning cube to a complete first-person dungeon crawler. One concept per chapter, ~20 lines of code each.

## Setup

```bash
pip install ursina
```

That's it. No build tools, no C++ dependencies, no shader compilation.
