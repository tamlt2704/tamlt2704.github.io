
## What Actually Happens

**Heat transfer** follows three mechanisms:

1. **Conduction**: heat flows through materials (engine block to coolant)
2. **Convection**: moving fluid carries heat away (radiator airflow)
3. **Radiation**: hot objects emit infrared (minor for game engines)

The key equation — **Newton's Law of Cooling**:

```
dT/dt = -h × (T - T_environment)
```

The rate of cooling is proportional to the temperature difference. Hot objects cool fast; warm objects cool slowly.

**Heat generation** from the engine:

```
dT/dt = (power_input / heat_capacity) - h × (T - T_env)
```

Where:
- **power_input** = heat generated by engine (watts)
- **heat_capacity** = how much energy to raise temp by 1° (J/°C)
- **h** = cooling coefficient (how fast heat escapes)
- **T_env** = ambient temperature

## The Simulation

```python
dt = 0.016

# Engine properties
heat_capacity = 50.0    # J/°C (thermal mass of engine)
cooling_coeff = 0.8     # Cooling rate (higher = better cooling)
ambient_temp = 20.0     # °C (environment)
max_temp = 120.0        # °C (overheat threshold)

# Heat generation
idle_power = 5.0        # Watts when idling
accel_power = 80.0      # Watts when accelerating hard
boost_power = 200.0     # Watts with nitro boost

# State
temp = ambient_temp
overheated = False

# Driving scenario: idle, accelerate, cruise, boost, cool down
scenario = [
    (0, 3, "idle"),
    (3, 8, "accelerate"),
    (8, 12, "cruise"),
    (12, 14, "boost"),
    (14, 20, "idle"),
]

time = 0.0
print(f"{'Time':>5} {'Temp':>6} {'dT/dt':>7} {'State':>12} {'Status'}")
print("-" * 50)

for frame in range(1250):  # 20 seconds
    # Determine current action
    action = "idle"
    for start, end, act in scenario:
        if start <= time < end:
            action = act
            break

    # Heat input based on action
    if action == "accelerate":
        power_in = accel_power
    elif action == "boost":
        power_in = boost_power
    elif action == "cruise":
        power_in = accel_power * 0.4
    else:
        power_in = idle_power

    # Newton's law of cooling + heat generation
    heating = power_in / heat_capacity
    cooling = cooling_coeff * (temp - ambient_temp) / heat_capacity
    dT = (heating - cooling) * dt

    temp += dT

    # Overheat check
    status = ""
    if temp >= max_temp and not overheated:
        overheated = True
        status = "⚠ OVERHEAT!"
    elif temp < max_temp - 10 and overheated:
        overheated = False
        status = "✓ cooled down"

    time += dt

    if frame % 62 == 0:
        print(f"{time:5.1f} {temp:6.1f} {dT/dt:7.3f} {action:>12} {status}")

# Equilibrium temperature for each mode
print(f"\nEquilibrium temperatures (where heating = cooling):")
for name, power in [("idle", idle_power), ("accel", accel_power),
                     ("cruise", accel_power*0.4), ("boost", boost_power)]:
    eq_temp = ambient_temp + power / cooling_coeff
    print(f"  {name}: {eq_temp:.1f}°C {'(OVERHEAT)' if eq_temp > max_temp else ''}")
```

## Entropy: Why Engines Aren't Perfect

The **Second Law of Thermodynamics**: heat flows from hot to cold, never the reverse. No engine converts 100% of heat to work.

```python
# Carnot efficiency (theoretical maximum)
T_hot = 400 + 273   # Combustion temp in Kelvin
T_cold = 20 + 273   # Environment temp in Kelvin
efficiency = 1 - (T_cold / T_hot)
print(f"Max theoretical efficiency: {efficiency*100:.1f}%")
# About 56% — the rest becomes waste heat
```

This is why engines produce waste heat. It's not a bug, it's physics.

## The Fix for *Toss It!*

Before:
```python
# WRONG: instant temperature, no cooling
if accelerating:
    engine_temp += 50
```

After:
```python
# CORRECT: gradual heating with Newton's law of cooling
heat_in = power_output / heat_capacity
heat_out = cooling_coeff * (engine_temp - ambient) / heat_capacity
engine_temp += (heat_in - heat_out) * dt

if engine_temp > max_temp:
    trigger_overheat_warning()
```

Now the engine heats up realistically — fast under load, slow at idle — and cools down when you ease off. Players can manage heat by alternating between boost and cruise.

## What You Learned

- **Newton's Law of Cooling**: dT/dt = -h(T - T_env) — cooling rate ∝ temperature difference
- **Equilibrium temperature**: where heat in = heat out (T_eq = T_env + P/h)
- **Heat capacity** — thermal mass, how much energy per degree
- **Entropy** — heat flows hot→cold, engines can't be 100% efficient
- **Game mechanic** — temperature becomes a resource players must manage
