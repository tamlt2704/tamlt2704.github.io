# Physics Fun — From Falling Apples to Orbiting Planets

A narrative-driven physics course where every concept is a mini-simulation you can run. You're a game developer at **GravityLab Studios** building a physics sandbox game. Each chapter adds a new mechanic — and each mechanic is real physics, explained with code and visuals.

## Episodes

| # | Title | The Scenario | What You Learn |
|---|---|---|---|
| 00 | [Before You Start](chapter-00-overview.md) | — | Setup, units, the simulation loop |
| 01 | [Dropping Things](chapter-01-freefall.md) | Objects float instead of falling | Gravity, acceleration, v = v₀ + at |
| 02 | [Throwing a Ball](chapter-02-projectiles.md) | Cannonball goes in a straight line | Projectile motion, 2D vectors, parabolas |
| 03 | [Pushing Crates](chapter-03-forces.md) | Crates slide forever on ice | Newton's laws, F=ma, friction, normal force |
| 04 | [Bouncing Off Walls](chapter-04-collisions.md) | Ball passes through walls | Elastic/inelastic collisions, momentum, restitution |
| 05 | [Swinging Ropes](chapter-05-pendulums.md) | Rope physics look fake | Pendulums, angular velocity, period |
| 06 | [Rolling Down Hills](chapter-06-inclines.md) | Objects teleport down slopes | Inclined planes, component forces, torque intro |
| 07 | [Springs and Trampolines](chapter-07-springs.md) | Trampoline has no bounce | Hooke's law, spring constant, damping |
| 08 | [Spinning Wheels](chapter-08-rotation.md) | Wheels slide instead of rolling | Angular momentum, moment of inertia, rolling |

## Prerequisites

- Python 3.10+ (simulations)
- matplotlib (optional, for plots)

## Philosophy

Every physics concept is introduced because the game looks wrong without it. You'll see the broken simulation first, then learn the physics that fixes it. The fake physics comes first. The real physics follows.
