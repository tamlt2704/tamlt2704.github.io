## Phase 2: Growth (Months 3-6)

### YouTube Strategy

**Video Types That Work for Dev Content:**
1. **Build-along tutorials** (15-30 min) — "Build X from scratch"
2. **Concept explainers** (5-10 min) — "How React Native navigation actually works"
3. **Tool comparisons** (10-15 min) — "Expo vs bare React Native in 2026"
4. **Code reviews** (10-20 min) — Review open source or viewer code
5. **Day-in-the-life / setup tours** — Lower effort, high engagement

**Production Tips:**
- Screen recording + voiceover is fine. No face cam needed initially.
- Use OBS (free) for recording
- DaVinci Resolve (free) for editing
- Invest in a good mic ($50-100 makes a huge difference)
- Thumbnail: bold text + code snippet or result screenshot
- Title formula: "[Action] + [Specific Thing] + [Timeframe/Qualifier]"
  - "Build a Production App with React Native in 2026"
  - "I Replaced Redux with 50 Lines of Code"

**SEO for YouTube:**
- Research with vidIQ or TubeBuddy (free tiers)
- Target keywords with search volume but low competition
- First 48 hours matter most — share everywhere

### Medium Strategy

**Getting Published in Big Publications:**
1. Write 3-5 posts on your own profile first
2. Apply to publications: Better Programming, Towards Data Science, Level Up Coding
3. Follow their style guides exactly
4. Pitch with a headline + 2-sentence summary

**What Performs on Medium:**
- "X things I learned building Y" (listicles)
- "Why I switched from X to Y" (opinion + technical)
- "The complete guide to X" (comprehensive reference)
- "X mistakes developers make with Y" (pain points)

**Cross-posting Strategy:**
- Publish on YOUR blog first (with the date)
- Wait 1-2 days, then cross-post to Medium with canonical URL
- This gives you SEO credit while getting Medium's distribution

### Newsletter Growth

**Lead Magnets (free things that get signups):**
- React Native starter template
- Algorithm cheat sheet PDF
- Docker commands reference card
- "My VS Code setup" config files

**Where to Put Signup Forms:**
- End of every blog post ✅ (added)
- YouTube video descriptions
- Twitter/X bio and pinned tweet
- GitHub profile README
- Dedicated landing page

## Phase 3: Monetization (Months 6-12)

### Revenue Streams by Effort

**Low effort, recurring:**
- YouTube ad revenue (~$3-8 per 1,000 views for dev content)
- Medium Partner Program (~$100-500/month with consistent posting)
- Affiliate links (hosting, tools, courses — 10-50% commission)

**Medium effort, high return:**
- Newsletter sponsorships ($50-200 per issue at 1,000+ subscribers)
- YouTube sponsorships ($500-5,000 per video at 10K+ subscribers)
- Digital products (templates, boilerplates — $10-50 each)

**High effort, highest return:**
- Courses ($49-199 each, sell to your audience)
- Consulting/freelance ($100-300/hr, inbound from content)
- Cohort-based workshops ($200-500 per seat)

### Tools for Selling

**Courses:**
- Lemon Squeezy (easiest, handles tax globally)
- Gumroad (simple, well-known)
- Self-hosted with Stripe (more control, more work)

**Email:**
- ConvertKit (best for creators, free up to 1,000 subs)
- Buttondown (minimal, developer-friendly)
- Beehiiv (good for monetization features)

**Payments:**
- Stripe (direct integration)
- Lemon Squeezy (Stripe wrapper that handles VAT/tax)
- Paddle (alternative merchant of record)
