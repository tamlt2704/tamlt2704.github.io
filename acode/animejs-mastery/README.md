# Anime.js Mastery

The site feels cheap. CSS transitions can't coordinate 15 elements. The client expects luxury-grade motion. 14KB. No dependencies. Learn Anime.js from simple fades to full choreography.

## The Story

You're at **Lumina** — a creative agency building a site for a Swiss watchmaker. The hero section: a watch assembles itself piece by piece. Specs count up on scroll. Navigation morphs. Every interaction has weight. CSS can't do this. You have 2 weeks.

## Why Anime.js

- 14KB gzipped, zero dependencies
- Timelines, stagger, spring physics, SVG paths — all built in
- MIT license (free)
- Simpler API than GSAP, more powerful than CSS

## Prerequisites

```bash
npm install animejs
```
