# SVG Animation Mastery

The product feels dead. Competitors have butter-smooth transitions, self-drawing charts, and morphing icons. You have hard cuts and static spinners. Time to learn SVG animation — from basic shapes to production motion design.

## The Story

You're at **Orbitly** — a SaaS startup losing deals because the product *feels* cheap. The design lead needs 12 animations in 3 weeks: loading states, data visualizations, micro-interactions, page transitions, and an animated logo. CSS transitions aren't enough. Lottie is too heavy. You need SVG from the ground up.

## Key Insight

SVG is not "images from Figma." It's a programmable graphics language. Every element is a DOM node. Every attribute is animatable. Every path is a mathematical curve you can manipulate with code.
